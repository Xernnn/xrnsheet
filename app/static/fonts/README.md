# MiSans

`MiSansLatinVF.woff2` is the editor's own font: MiSans Latin by Xiaomi, the official variable cut
(weights 150 to 700), unchanged. `app.css` loads it for the window; the pages of music keep their own
engraving fonts. The desktop app carries it inside `app/`.

MiSans by Xiaomi, used under the MiSans font licence (free for commercial use when the software
notes that it uses MiSans). The font files are not covered by this repository's licence.
<https://hyperos.mi.com/font/en/>
